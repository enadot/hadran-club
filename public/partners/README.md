# לוגואים של בתי העסק השותפים

התיקייה הזו מחזיקה את הלוגואים של הרשתות והחנויות השותפות. כל עוד היא ריקה, כל
מקום באתר שמציג בית עסק נופל בחזרה ללוחית ראשי התיבות בעברית — זו התנהגות תקינה,
לא באג.

## איך מוסיפים לוגו

1. מניחים את הקובץ כאן, למשל `public/partners/hadar.svg`.
2. מוסיפים שדה `logo` לרשומה של אותו בית עסק ב-`lib/data/partners.ts`:

   ```ts
   {
     name: "בגדי ילדים · הדר הבית",
     category: "ביגוד והנעלה",
     city: "ירושלים",
     branches: 3,
     exclusive: true,
     logo: "/partners/hadar.svg",
     benefit: "הטבה שזמינה אך ורק לחברי הדרן קלאב",
     terms: [...],
   }
   ```

זה כל מה שצריך. הלוגו נכנס אוטומטית לשלושת המקומות שמציגים בית עסק — רצועת
"איפה הכרטיס עובד" בעמוד הבית, שורות עמוד `/benefits`, וחלון פרטי בית העסק —
כי כולם מרונדרים דרך `components/brand/PartnerLogo.tsx`.

## דרישות לקובץ

- **פורמט** — SVG מועדף. אם אין, PNG שקוף ברוחב 200px לפחות.
- **רקע** — שקוף. הלוחית שמאחורי הלוגו היא בצבע `--color-canvas-soft`, ורקע לבן
  קבוע ייראה כמו ריבוע תקוע עליה.
- **יחס** — הלוגו מוצג ב-`object-contain` בתוך ריבוע, כך שלוגו רחב מאוד יופיע קטן.
  עדיף מארק מרובע או קרוב לזה, לא לוקאפ ארוך עם טקסט.
- **שוליים** — לא צריך להוסיף padding בקובץ עצמו; הקומפוננטה כבר מוסיפה מרווח פנימי.
- **שם הקובץ** — אנגלית, אותיות קטנות ומקפים בלבד.

## מה לא לעשות

- לא להניח כאן את הלוגו של הדרן קלאב עצמו — הוא יושב ב-`public/` בשורש
  (`logo-lockup.svg`, `logo-mark.svg`).
- לא להוסיף לוגו של רשת שאינה שותפה בפועל.
